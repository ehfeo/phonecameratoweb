# 手机摄像头投屏工具

将手机摄像头拍摄的画面实时投屏到电脑查看的工具。手机无需安装 App，用浏览器扫描电脑端显示的二维码即可开始传输。

## 特性

- 免安装：电脑端启动后显示二维码，手机浏览器扫码即可

- 传输可靠：视频经 WebSocket 服务器中转（MediaRecorder → MediaSource），跨网段、手机热点同样可用

- 多手机：可多台手机同时接入，在电脑端切换显示哪一路画面，支持全屏

- 手机端可切换前后摄像头、调节码率 / 分辨率 / 照片质量、一键拍照并保存到电脑

- 支持 http 自动跳转 https；端口可在网页内配置并重启生效

## 使用

1. 启动 `phonecam.exe`（会自动打开电脑端页面），或用 `go build -o phonecam.exe .` 自行编译
2. 手机与电脑连接同一局域网（或连电脑热点）
3. 用手机浏览器扫描电脑端页面的二维码，接受证书提示并授权摄像头
4. 画面即可实时显示在电脑端

## 技术要点

- 后端用 Go 实现 HTTPS 服务与 WebSocket 信令/视频中转，自动生成并持久化自签名证书，避免反复告警

- 手机端用 `getUserMedia` + `MediaRecorder` 采集，电脑端用 `MediaSource`(MSE) 播放

- 端口可通过网页「服务设置」保存到 `data/config.json`，重启后生效

## 参数

- `-port`：监听端口（默认 8443，也可通过网页配置）

- `-no-open`：启动后不自动打开浏览器
